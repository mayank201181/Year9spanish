# Year 9 IGCSE Spanish (`Year 9`) — Architecture Notes

- **Syllabus**: Pearson Edexcel International GCSE Spanish (`Year 9`), graded 9–1.
- **Topics (`lib/topics/meta.ts`)**: 5 Official Edexcel Topic Areas (A–E) + 2 IGCSE Grammar Mastery units.
- **Verb Engine (`lib/spanish/verbs.ts`)**: 8 tenses/moods (`present`, `preterite`, `imperfect`, `near-future`, `future`, `conditional`, `perfect`, `subjunctive`).
- **Validation**: `npm run gen && npm run validate && npm test && npm run lint && npm run build`.
